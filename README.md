# Appscrip Task - Product Listing Page (PLP)

A professional, responsive, and SEO-optimized Product Listing Page built with **Next.js 15**, **React 19**, and **Tailwind CSS 4**. This project showcases a modern e-commerce interface with advanced filtering, server-side rendering, and a seamless user experience.

## 🚀 Live Demo
Check out the live application here: [Appscrip-Task-Chintan-Vekariya](https://github.com/ChintanVekariya9189/Appscrip-Task-Chintan-Vekariya)

## ✨ Key Features
- **Responsive Design**: Fully optimized for Desktop, Tablet, and Mobile devices.
- **Advanced Filtering System**: 
  - Dynamic category filters (Ideal For, Occasion, Work, Fabric, etc.).
  - Single-accordion behavior for a clean sidebar interface.
  - Price range filtering.
- **Seamless UX**: 
  - Smooth horizontal scrolling news ticker in the banner.
  - Custom favorite (heart) icons with smooth interactions.
  - Optimized DOM size for better performance.
- **SEO & Performance**:
  - Server-Side Rendering (SSR) for faster initial loads and better indexing.
  - Semantic HTML5 structure (H1, H2 tags).
  - Comprehensive Meta Tags and Open Graph (OG) support.
  - JSON-LD Schema markup for products.
  - Optimized images with appropriate alt text.
- **Local Data Integration**: High-speed performance using optimized local product data (with fallback capability for API integration).

## 📦 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/ChintanVekariya9189/Appscrip-Task-Chintan-Vekariya.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Appscrip-Task/my-app
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## 📁 Project Structure
- `app/`: Next.js App Router (pages and layouts).
- `components/`: Reusable UI components (layout, home, seo).
- `data/`: Static product data and constants.
- `public/`: Static assets (images, icons).
- `globals.css`: Global styles and Tailwind configuration.
